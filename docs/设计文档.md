# E-QTSF 系统设计文档

事件感知质量时序预测模型 + 机械加工质量管理系统
（参考：EVENTTSF, arXiv:2508.13434；EventTime, CIKM 2026；
《机械加工企业质量管理系统的设计与实现》）

---

## 1. 设计定位

导师要求：**把关注点放在模型创新上，吃透参考模型后搭建自己的模型**。
因此本设计以 E-QTSF 模型为核心，管理系统作为模型落地与价值呈现的载体：

```
模拟/真实质量数据 ──► 事件注入（6大类×13子类×4严重度）
        │
        ▼
E-QTSF 模型（自回归流匹配 + 多尺度编码 + 事件融合
             + 事件感知时间步 + 动态对比学习）
        │  28 天合格率概率预测 + 超标概率 + 事件归因
        ▼
质量管理系统（FastAPI + Vue3）
   预测预警页：红/橙/黄预警 → 一键生成 NCR → 闭环处置
   看板 / SPC（X̄-R、P 图、PPM） / 基础数据 / 权限
```

## 4. E-QTSF 模型设计

### 4.1 问题定义（对齐 EVENTTSF Definition 2）

序列按 7 天分段离散化：{x_s}（段不重叠、并集为全序列），每段对齐段内事件
c_s（无事件为 NULL）。给定历史 H_x（84 天=12 段）与未来已知事件
F_e = {c_s}，输出未来 4 段（28 天）的概率预测。

### 4.2 网络结构（model/modules.py）

1. **EventEncoder**：事件特征（6 类型 + 13 子类型 + 4 严重度 multi-hot + has_event
   + 严重度权重 = 25 维）→ MLP 嵌入；NULL 事件 → 可学习空嵌入；
   严重度权重额外经 Linear 加性注入（创新点 1）。
2. **MultiScaleEncoder**（EventTime 3.1.1）：日视图 Transformer（细粒度波动）、
   周视图 GRU（中周期）、月视图 GRU（季节/劣化周期）；跨视图交叉注意力
   （长周期视图为 Q，日视图为 K/V）→ 上下文记忆 (B, 84+15, d)。
3. **EventFusion**（EventTime 3.1.2，translate-locate-imprint）：
   首个未来事件嵌入为 Q 对短期 28 天序列两层注意力 → 事件条件化短期表征；
   注意力权重 β 输出为**可解释归因**（哪些天受事件影响）。
4. **EventTimestep**（EVENTTSF 3.2 + 创新 1）：
   t ~ U(0,1) → t' = F⁻¹_Beta(α(c),β(c))(t)，α/β 由事件嵌入预测；
   PyTorch 未实现 Beta.icdf → 自实现可微连分式 CDF + logit 空间牛顿迭代
   （model/beta_icdf.py）。
5. **Denoiser**（EVENTTSF 3.2）：M_θ(Z_{s-1}, x_s^t, c_s, t') → 速度场 v̂
   与更新潜状态；段/状态/事件/时间四 token + Transformer 编码 + 上下文记忆
   交叉注意力；速度头 (seg×C) + 状态头（残差更新）。

### 4.3 训练（Algorithm 1 风格）

每段 s：采样 t~U(0,1) → t'=φ(t,c_s)（事件感知时间步）；
OT 路径 x^t = (1-t')x_s + t'ε，目标速度 v = ε - x_s；
单次前向同时输出 (Z_s, v̂_s)（状态由带噪段更新，与论文训练一致）；
损失 L = L_FM + 0.3·L_contrast + 0.1·L_similarity。

### 4.4 动态对比学习（EventTime 3.2，创新点 3）

- 启发式相似度 S_h：末 28 天统计量（均值/方差/极值/趋势斜率/波动比/近期冲击）
  余弦 + 事件属性（multi-hot Jaccard + 严重度接近度）加权；
- 学习式相似度 S_l：融合表征投影后余弦；
- 动态加权 S = S_h^λ · S_l^(1-λ)，λ 随轮次 0.3→0.9；
- top-k 正对（S>0.75）InfoNCE + 相似度正则 (S_l - S_h)²；
  ——解决致命/严重事件占比仅 ~35%、单独学习易过拟合的问题。

### 4.5 推理与归因（Algorithm 2 风格）

历史 12 段（t=1 干净段）自回归构建初始状态 Z_0 → 逐段 ODE 积分
（Euler 12 步，t: 1→0，事件感知时间步映射）→ 段去噪后干净更新状态；
100 条采样轨迹 → 中位数/10%/90% 分位/超标概率。
**逐事件归因**：仅保留单个未来事件 vs 全 NULL 两次采样的预测差 |Δ|，
量化每个事件对预测的影响强度（server/main.py forecast_run）。

### 4.6 与 EVENTTSF 的差异点汇总

| 维度 | EVENTTSF | E-QTSF |
|---|---|---|
| 事件来源 | 自然语言文本嵌入（OpenAI text-embedding） | 结构化质量事件本体（类型/子类型/严重度 multi-hot + 可学习嵌入，工业现场事件天然结构化） |
| 时间步重参数化 | Beta(α(c),β(c)) | α 额外受**严重度权重**缩放（致命事件→更细去噪） |
| 上下文 | 单一历史段+潜状态 | + **日/周/月多尺度**与跨视图注意力（设备劣化/季节） |
| 表征学习 | 无 | **动态对比学习**（稀疏高严重度事件） |
| 输出使用 | 概率预测指标 | + **逐事件归因**与**超标概率预警→NCR 闭环**（管理落地） |

## 5. SPC 模块（补原论文空白）

- X̄-R 图：inspection_value 每日 5 实测值，A2=0.577、D4=2.114（n=5）；
- P 图：批次不合格率 p̄ ± 3√(p̄(1-p̄)/n)；
- PPM：缺陷率×10⁶；失控点计数展示于看板。

## 6. 安全与权限

JWT（HS256，12h）+ PBKDF2（100k 迭代）+ 角色矩阵：
ADMIN 全部；INSPECTOR 查看/建 NCR；ENGINEER 查看/处置 NCR；未授权 403。
